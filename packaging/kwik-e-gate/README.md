# Kwik-e-gate

Install the local code gate and receipt CLI for coding agents:

```bash
python -m pip install kwik-e-gate
kwik-e-gate --help
```

This small distribution installs the tested `hermes-gate` engine from the same
Kwik-e-gate release. It contains no separate runtime. See the
[product README](https://github.com/hermes-labs-ai/kwik-e-gate#readme) for setup,
check selection, receipts, and the source-pinned GitHub Action.
